# Agentic Delivery Handbook

> **Working draft. One part is written: [Part 3, threat modelling](parts/03-threat-modelling/README.md).
> Start there.** The other parts are outlines, marked *not yet written* below. Every term is defined in
> [the glossary](reference/example-system.md#glossary).

How to run a whole software engagement with agents – from the first requirement to the shipped
surface.

**Every stage produces an artefact that declares who it is for, what binds, and how it is proved
done.** The agents run unattended because of that, not because the prompts are good.

The early stages are where those artefacts get written, and they need a person in the room. Part 3
shows what that looks like.

Each part is a folder with three things in it: **a guide** written for you, **a prompt** you paste
into an agent session, and **templates** for every file the process produces.

There is nothing to install and nothing that runs. The templates are empty skeletons – the thinking
is still yours.
