# Agentic Delivery Handbook

> **Working draft.** Nothing here is finished.

How to run a whole software engagement with agents — from the first requirement to the shipped
surface.

**Every stage produces an artefact that declares who it is for, what binds, and how it is proved
done.** The agents run unattended because of that, not because the prompts are good.

This is not a repository to clone. Every part ends with **the smallest version that works**, so you
build your own.
