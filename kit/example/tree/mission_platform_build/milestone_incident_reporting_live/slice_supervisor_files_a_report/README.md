# Slice · A supervisor files a report

## Goal

A supervisor opens the form on the site's managed device, describes what happened in their own
language, and the report is in the canonical store before they have left the screen.

## Done-when

Demonstrated on a managed device at one site: a report filed in a language other than the working
language, then read back from the store with its language recorded and its text unchanged.

## Boundaries

- The form collects what the intake contract defines and nothing else.
- No translation here. The report is stored as written.
- Managed devices only. A report is never filed from a personal phone.

## Inherited context

- The intake contract is the single definition of a report. The form, the endpoint and the store are
  all generated from it or checked against it.
