# Feature · The dashboard's chart parts

## Goal

The dashboard is built from a small set of chart parts that all behave alike: one legend, one way of
highlighting a site, one keyboard model, one way of showing a suppressed cell.

## Done-when

Each part in the design reference's inventory exists in the component workbench and measures the same
as the reference, in every supported browser engine.

## Status – no packet

Waits on what a suppressed cell is. Every part has to draw one.
